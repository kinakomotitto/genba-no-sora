# 現場の空 v0.43 — プライベート地名検索・お気に入り

## 使い方
- ホームの現在地表示の下に「地名から天気を探す」を追加。2文字以上の市区町村名や地名を入力して「検索」を押す。
- Open-Meteo Geocoding API（`language=ja`）の最大8件を候補表示する。同名地名は都道府県・国名を添えて選び分ける。
- タップした地点の気温・風・降水確率・時間別予報・モデル比較・レーダーを既存の表示方式で見られる。
- 「⌖ 現在地に戻る」で通常のGPSホームへ復帰できる。
- 表示中の検索地点を「♡ お気に入りに保存」。お気に入りは端末内に最大20地点保存し、いつでも開く・削除できる。
- お気に入りは**仕事の「保存した現場」と別管理**。表示中の検索地点は現場登録されず、目視天気記録も行わない。
- 検索した地点の表示はセッション中のみ。次回アプリを開くとGPSホームが初期表示となる。再度見るときはお気に入りから選ぶ。

## データ・安全性
- 検索した地名の文字列は外部のOpen-Meteo Geocoding APIへ送られる。選択した地点の座標は既存のOpen-Meteo予報APIなどへ送られる。
- お気に入りの名前・座標はSafari/iPhone内の`localStorage`（`genbanosora.private-places.v1`）に保存。サーバー同期なし、再インストールやSafariデータ消去で失われる場合がある。
- 保存現場、現場メモ、現地天気記録、アメダス研究データ、通知設定、自動学習・自動補正フラグは変更しない。
- 通信できない場合は地名の新規検索は不可。お気に入りは一覧表示でき、対象座標の**以前取得した天気**があればその古い予報として表示可能。
- 地名検索は地域によって候補が不完全で、API利用規約や商用利用可否は別途確認が必要。APIで見つからない場合は別の地名表記を試す。
- 天気は参考予報で、気象警報・現場の作業中止判断に使うものではない。検索地点の位置とGPS現在地は画面上で区別する。
