# 現場の空 v0.40 — 「現在地」に県・市区町村／町名の2段表示

2026-11-11

## ユーザー合意済みデザイン

**ホームの現在地**を以下の形にする：

- **1段目**：⌖ 現在地　［青森県・八戸市］（淡いピンクのコンパクトなラベル）
- **2段目**：尻内町（少し控えめな細い文字）
- 地名が長い場合は「…」で省略。今の Soft Pink の配色、右側「現場一覧へ」、下部ナビ、現在地GPS/天気を維持
- GPS取得中・位置情報未許可・地名API未応答では、従来のGPSステータス行を表示。県・市区町村が確定したらGPS座標の行の代わりに町名行を表示し、ホームはすっきりした2段
- 町名がないときでも、自治体コードが正しければ「青森県・八戸市」の1段は表示。自治体コードが取れないときは県名や市名を**町名から推測せず**、従来のGPS表示に戻す

## 地理院データの扱い

- 国土地理院の既存API `https://mreversegeocoder.gsi.go.jp/reverse-geocoder/LonLatToAddress` の返却例：
  `{"results":{"muniCd":"02203","lv01Nm":"尻内町"}}`。
- `muniCd` があれば、**国土地理院 gsimapsの自治体名対応表**（全1,919自治体コード）から都道府県名と市区町村名を確定。
- 自治体名表は `municipalities-gsi.js` に**公開データの2026-11-11時点のスナップショット**を同梱。出典：[国土地理院 gsimaps/js/muni.js](https://github.com/gsi-cyberjapan/gsimaps/blob/gh-pages/js/muni.js)。APIの `02203` は公式表で `2203` に対応するため先頭0を正規化
- 市区町村の政令市行政区に全角空白がある場合は表示上詰める。例：札幌市　中央区 → 札幌市中央区
- 例：青森県・八戸市／尻内町、青森県・東北町／字ガス平、岩手県・北上市／（町名未提供）

## プライバシーと耐障害性

- **精密GPSを送らない**：既存v0.39と同じく緯度・経度を小数3桁へ丸めた値だけを地理院APIへ送る
- 自治体コード→名前の表はアプリに**事前同梱**するため、自治体名を調べる追加通信は発生しない
- 現場名・保存現場のメモ、日々の天気記録・学習データは、地名検索のために外部送信しない
- この端末のみ24時間キャッシュ。v0.39の町名だけのキャッシュを v0.40 では流用せず、**新たに県・市区町村まで検証済みのキャッシュ**として保存
- GSIサービス不通/圏外/不明の自治体コードなら県市町村名を無理に表示せず、天気表示は継続。古い検索応答を位置変更後に表示させない
- PWA Service Worker shell version **v0.40**。地理院自治体コード表をオフラインキャッシュへ追加

## 留保

この表示は地理院地図で取得できる**付近の地名**であり、GPS精度や行政境界近くで実際の現場名と異なる可能性がある。町名の問い合わせは任意のUI補助であり、天気APIの応答・伐採作業の安全判断には影響しない。iPhone実機の確認は別途必要。
