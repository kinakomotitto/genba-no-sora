# 現場の空 v0.38 — 目視の現地天気と、取得済み3モデル予報の端末内照合

2026-11-11 / **本番予報の自動補正は今までどおり OFF。**

## 概要

天気記録ボタン（晴れ・曇り・雨・雪）を押すと、これまでiPhoneに保存済みだった予報を確認し、**記録時点より前に取得した**気象庁MSM、ECMWF IFS、DWD ICONのモデル別の天気区分と照合する。結果はその記録と**同じ端末のlocalStorageだけ**に保存。現場名・GPS座標・記録・採点結果をサーバーへ送信しない。

今までも記録した天気は端末に保存できていたが、予報と比べるには過去の予報を後から取得する必要があった。新機能では事前保存した予報データをその場で読み、**後知恵による精度の水増しを防ぐ**。

## 記録の手順

1. ホームで現在地の天気を開くと、以前からある「3モデル比較」が予報を取得して端末に最大14日分のスナップショットを保存する。v0.38からは風・雨とともに、対応モデルの**瞬間的な天気区分（weather_code）**も記録する
2. GPSが新しく取得され、実際にいる場所と予報地点が同じであることを確認する
3. 実際に空を見たときに晴れ・曇り・雨・雪のボタンを押す。天気記録はこれまでどおり最大500件保存され、同一地点で5分以内の押し直しは1件に集約
4. 端末に残っていた**記録前に取得済みの予報**と瞬間的な天気区分を比較。一致・不一致・採点見送りの結果を記録と一緒に保存
5. ホームの記録欄に最新のモデル別照合結果、現場タブの「現地の天気記録」にモデル別一致数と観測した独立日数を表示する

## 正しい照合のための厳格な条件

- GPSが取得され、**15分以内・精度300m以内**。保存現場を開いている場合は現在GPSと保存地点が**500m以内**。現在地も参照地点と著しく離れていないこと
- 事前に端末に保存したモデル予報の地点と、実際のGPS位置が**700m以内**
- モデル予報は**記録した瞬間より前**、かつ24時間以内に取得したものだけ
- 天気予報の**対象時刻が記録の前後30分以内**。かつ、予報を取得した時刻より後の対象時刻でなければならない。対象時刻を過ぎた後に新たに取得した情報を過去の予報として扱わない
- 複数の同一モデルの事前予報がある場合は、**最新の有効な事前取得予報**を採用。欠測モデルは採点せず、0や晴れに読み替えない
- 天気区分の元データ `weather_code` は**指定した時間の天気**。これを目視と比較する。1時間降水量の合計値はその時刻の雨の目視と同じ意味ではないため、代用しない
- コード0,1=晴れ、3=曇り、雨/にわか雨/雷雨=雨、降雪/雪粒/雪のにわか雪=雪。**2（晴れ時々曇り）や霧・その他は曖昧なので照合対象外**
- 以前から保存されていた目視記録には、当時の `weather_code` を保存していない可能性があるため、**過去にさかのぼって採点しない**
- 一致数は目視の**参考診断**。同じ日に何回記録しても独立した日数としては1日。母数が少ない段階でモデルの優劣や精度改善と断定しない

## プライバシー・安全

- 天気を記録しても**端末から新たな通信を行わない**。すでにある3モデル予報取得リクエストは、今までどおりOpen-Meteoへ必要な予報地点の座標を送る。今回の天気記録・記録した現場名・照合結果は送らない
- 研究結果のGitHub公開、会社の現場データ収集、他ユーザーとの共有、自動モデル補正は**すべて無効**
- 4択は目視天気であり、気温や風速の数値測定、1時間降水量、気象警報の代わりにならない。天気を記録したこと自体を作業安全の根拠として扱わない
- Open-Meteoのモデルデータは気象モデル由来であり、雨と風の予測・安全基準の保証はない
- 記録や照合はブラウザlocalStorageに保存するため、アプリのデータ削除や端末初期化で消える。別端末へは同期しない

## 自動テストと保守

- `tests/test_observation_verification.cjs`: GPS鮮度・位置、3モデル共通の記録、WMO天気区分、後から得た予報の採点拒否、降水量の誤用回避、独立日数
- `tests/test_model_compare_snapshots.cjs`: Open-Meteo模擬レスポンス、天気コードを端末に保存、天気コード未対応モデルでも従来の風/雨比較を維持
- `tests/test_weather_record_integration.cjs`: アプリ本体の記録ボタン、記録/採点の端末保存、5分以内の重複、照合失敗時も記録を維持
- `tests/test_home_site_navigation.cjs`: 既存のGPS/ホーム/保存現場と新しいUIの回帰チェック
- 本番の予報取得APIとiPhone実機での挙動は、GitHubのCI成功だけでは保証できない。使用時に「3モデル比較」でweather_codeが得られること、iOS Safari/PWAのキャッシュ更新、GPS鮮度を実機で確認

## 将来

予報と目視の記録が十分な数・地域・季節で蓄積されれば、**端末内での公平な参考採点**を段階的に改善可能。公衆の長期学習へ使う場合には、個人の現在地・現場情報が漏れないように明示的な同意と匿名化の設計が必要。現時点では外部送信も自動補正も実装しない。
