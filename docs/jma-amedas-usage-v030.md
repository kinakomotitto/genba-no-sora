# v0.30 気象庁アメダスの利用条件・実装内容（2026-11-10）

## 結論
- 気象庁の公開コンテンツは、権利や個別制約がない限り、**公共データ利用規約 1.0（PDL1.0）** に従う。規約には**商用利用も可能**と明記。出典表示と加工した旨の表示が必要
- 気象庁ホームページのアメダス全国地図で用いられるJSONは、Web公開されたコンテンツであって、**公式に契約・仕様保証された開発者向けAPIではない**。現状はキー不要で参照できても、URL/JSON形式/容量/提供頻度が変わり得る
- したがって**短時間の大量リクエストはしない**。個別観測所1,300地点へアクセスせず、全国を1ファイルで取得する。気象庁の過去データCSVダウンロード画面を自動でクロールしない
- Open-Meteoは別サービス。Free APIは**非商用用途のみ**。たとえ無料配布/非売品でも、企業の社内業務に用いるなら有償の商用ライセンスが必要になり得る。Open-Meteo側と利用形態を確認するまでは業務用途での許諾済みと断言しない

## 追加した機能

### iPhoneで「近くのアメダス実測」
- ホームの折りたたみパネルは**ユーザーが開いた場合だけ**約3つの公開ファイルを取得
- 最新観測時刻： `/bosai/amedas/data/latest_time.txt`
- 全国観測所メタデータ：`/bosai/amedas/const/amedastable.json`
- 全国実測：`/bosai/amedas/data/map/YYYYMMDDhhmmss.json`（10分刻み）
- 選択中の位置座標は**APIへ送らず、端末内で距離計算**して風と降水の最も近い利用可能な観測所を選択
- 風：過去10分間の平均、降水：直近1時間の積算値。風と降水は違う観測所になる可能性があるので観測所名・距離を**それぞれ**明示
- 値の配列 `[value, quality]` のうち品質が0の場合だけ採用。他の品質値やnullは欠測とし、降水量ゼロとの混同を防ぐ
- 取得時刻が古い場合は警告。90分より古い公開時刻なら取得失敗扱い。全国のJSONは12分間メモリにキャッシュ
- 現場名/GPSをGitHubや学習サーバーに送らない。気象庁の公開URLを利用する際には通常のIP等のアクセス情報は先方へ伝わる
- 公式警報や安全基準に置き換わる数値ではない。個人の山林現場の高度・地形とは異なる

### 全国観測値の低頻度バックエンド収集
- `tools/amedas_snapshot.py` が1回あたり**最大3 GET**（最新公開時刻・観測所一覧・全国の1時間正時の観測マップ）だけを取得
- `.github/workflows/amedas-national.yml` で、午前9時12分、午後3時12分、午後9時12分、午前3時12分（日本時間）の**1日4回を予定**（GitHub Actionsの開始時刻は保証されない）
- 最新のJSONは `data/amedas/latest.json`、直近14日のコンパクトな記録は `data/amedas/recent/YYYY-MM-DD.jsonl` に保存
- 全国で200地点未満しか有効な観測値がない場合は更新を停止し、**全国取得成功と偽らない**
- 品質0以外は欠測にして残す（0mmの正常な降水とは区別）
- 元のJSONスキーマが変化した場合は例外を出し、既存最新データを上書きしない
- 初回のGitHub Actions本番稼働と実際のJMAレスポンスの整合は、マージ後に確認する必要がある
- GitHub公開リポジトリには全国の公開観測値しか書き込まない。訪問履歴・住所・現場名・個人のGPSを収集しない
- Gitにデータを何年分も貯めるのは効率的ではないため、将来は容量制限と長期集計用DBに移行する

## 未完成の部分
- **JMAアメダスの全国観測値と3つの予報モデルを自動照合して最適予測にする仕組みはまだ未完成**
- v0.28で作った検証計算器と接続するには、同じ公開観測所・同時刻で3モデルの**取得時点の予報スナップショット**を継続取得する必要がある
- JMA公式APIの仕様保証や安定的な大容量継続配信が必要になった場合には、気象業務支援センターや許諾された商用データ供給元を検討する
- 時間が経過した観測値は修正される場合がある。予報検証結果の品質・再現性を改善するには後日の訂正データも調べる
- 全国のアメダス地点と現場は必ずしも同じ風を観測しない。山や森林、鉄塔での強風リスクを現地観測として断定しない

## 料金
今回の**気象庁公開コンテンツを少ない回数だけ参照する試作コード自体**は有料データの契約や決済処理を追加しない。GitHub ActionsやPagesの無料枠等の使用量・条件は別途確認。将来の大規模収集は使用料/利用許諾を事前確認し、**勝手に有料契約を始めない**。
