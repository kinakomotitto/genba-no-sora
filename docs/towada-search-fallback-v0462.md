# 現場の空 v0.46.2 — 十和田市の地名検索フォールバック

## きっかけ
2026年11月14日、iPhoneのホーム検索欄に「十和田市」と入力すると「見つからなかったよ」と表示された。現場の空には国土地理院の市区町村リストに「青森県・十和田市」が既に登録されていたが、地名検索時の座標解決をOpen-Meteo geocodingの検索結果に依存していた。

## 修正
- Open-Meteoの検索結果に正しい「青森県・十和田市」が存在しない場合のみ、青森県公開オープンデータに登録された十和田市役所の地点（北緯40.612703、東経141.20591）を参考地点の候補にする。
- 参考地点の区別が付くよう、候補、選択地点の説明、お気に入り復元時に **「十和田市役所付近（青森県公開データ）」** と表示する。市域全体の気温を示すものではなく、地点の予報であることを説明。
- 正しい「青森県・十和田市」が通常のジオコーダーにあればそちらを優先し、値を置き換えない。
- 既存の国土地理院同梱市区町村データに十和田市があることを確認してからフォールバック。別の地名（例：十和田湖）への誤適用や、日本語漢字だけで座標を推測する挙動は禁止。
- 保存先は私用のお気に入りのみ。現場一覧、現場記録、プッシュ通知、モデル学習、現在地GPSは変更しない。
- PWAキャッシュを v0.46.2 に更新。ユーザーの保存情報は削除しない。

## 座標の裏付け
青森県の自治体オープンデータ「公共施設一覧」に十和田市役所庁舎（青森県十和田市西十二番町6-1）、緯度40.612703、経度141.20591として記載。
参照：https://opendata.pref.aomori.lg.jp/dataset/1478/resource/26339/content.html

## 動作確認
`tests/test_private_places.cjs` に、APIが0件でも十和田市の参考地点が見つかること、位置と出典ラベル、ワンタップ補完、別地名の誤判定防止、正しいAPI結果の優先、保存した私用お気に入りの復元、現場への不干渉を追加。
iPhone実機の動作確認は公開後に行う。
