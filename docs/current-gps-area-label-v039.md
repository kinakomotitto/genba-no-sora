# 現場の空 v0.39 — ホームの「現在地」横に短い日本語の町名を表示

更新：2026-11-11

## 表示
- ホームの「⌖ 現在地」の右に、**薄ピンクの小さな角丸ラベル**で付近の地名（例：尻内町）を表示する
- 下の「GPS取得 · 座標」と「現場一覧へ」ボタンは従来どおり。スマホの小さい幅では長い地名が「…」に省略され、ナビゲーションや天気カードを押しのけない
- 地名ラベルは**国土地理院の逆ジオコーダー**の `results.lv01Nm`（町・大字など）を使用。行政区画の厳密な確定や現在地をピンポイントで保証するものではない
- 市町村名（市、郡、町、村）を取得できないAPI結果からは、勝手に推定して付け足さない。まずは短い町名ラベルのみ
- GPS未許可・取得失敗・圏外かつ保存データ無し・国土地理院のサービス障害・対象外地域・戻り値が不正な場合は**ラベルを表示しない**。GPSや天気予報の表示は止めない
- 新しいGPSを取得したら地名を更新。保存現場を開いている間のGPS地名は描画しない。以前の地名検索が遅れて返っても新しい画面へ誤表示しない

## 位置情報とプライバシー
- サードパーティの公開国土地理院API `mreversegeocoder.gsi.go.jp/reverse-geocoder/LonLatToAddress` へ、**GPSの小数3桁に丸めた緯度・経度**のみ送る。実座標より数十m程度粗い精度で問い合わせる
- アプリに保存されている会社現場名・現場メモ・手動の天気記録・通知トークンは送信しない
- 地名を再取得しなくて済むよう、直前の丸め座標と地名を**この端末のlocalStorageへ24時間キャッシュ**する。位置が変われば再取得する
- 国土地理院のAPIへの接続にはネット通信が必要。付近の地名は目安であり、住所検索が失敗してもGPSと天気予報、現場情報は継続する
- 位置の問い合わせを行うことは、既存のOpen-Meteo天気APIへの座標送信とは**別の通信**である。UIの設定欄にも説明を追加

## テスト
- `tests/test_location_label.cjs`: 日本語の町名、数値座標を3桁に丸める、キャッシュ、24時間有効期限、オフラインの既存ラベル表示、非対応地理、失敗時の安全な非表示、遅れて帰る応答の破棄
- `tests/test_home_site_navigation.cjs`: ホーム/保存現場切り替えとGPSの表示処理、ラベル要素の存在、バージョン v0.39
- iPhoneのPWAオフラインシェルに `location-label.js` を追加。公開後のSafariキャッシュ切替を反映
- **実機のGPSと国土地理院API応答**はローカルの自動テストでは保証できないため、iPhoneで確認が必要

## データの扱い
気象庁アメダスの機械学習研究データ、現地天気記録と事前予報の照合、通知設定、GPSに紐づく保存現場、本番予報の自動補正は変更しない。

参考：[国土地理院 地理院地図](https://maps.gsi.go.jp/)、[地理院地図のコード](https://github.com/gsi-cyberjapan/gsimaps)。
