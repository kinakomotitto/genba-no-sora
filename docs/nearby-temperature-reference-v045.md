# 現場の空 v0.45 — 近くのアメダス実測気温と予報の参考比較

## ユーザー要望
箱根湯本周辺でアプリ13℃に対して体感10℃前後。体感は温度計の実測ではないため誤差と断定せず、気象庁アメダスの**近くの実測気温**を照合できるようにする。

## UI
- ホーム（保存現場・検索したプライベート地点を含む）に従来からある **「🌿 近くのアメダス実測」** を開くと、従来の風・雨に加え、上段に3つの数値を表示する。
  - **☁️ アプリ予報**：選択地点のOpen-Meteo `current.temperature_2m`。温度は小数1桁。
  - **🌿 近くの実測**：選択地点から80km圏内の気温が有効な最寄りアメダス観測所の`temp`（品質フラグ0のみ）。
  - **差（予報−実測）**：時刻と鮮度が比較可能な場合にのみ符号付き表示。
- 観測所名・直線距離・標高（取得可能な場合）を表示。
- 既存のアメダス観測状況欄には観測時刻・観測値の経過分数が残る。差を表示する場合はさらに**予報時刻と観測時刻**を併記。

## 信頼性と安全な判定
- 比較許可：予報気温と観測気温がともに有効、予報が保存された古い値ではない、予報の対象時刻と実測時刻が30分以内、実測が45分以内、予報取得が90分以内。条件に合わない場合は差を「—」にして理由を表示。
- 観測地点はGPS・保存現場・検索地点と**別地点**。特に箱根や山間地では標高差・地形・夜間放射冷却で数℃変わることがある。差を「予報誤差」「学習の正解」「現場の外気温」と断定しない。
- 有効観測がない場合は他所の温度を捏造せず「—」。アメダス地点に気温の観測機能がない場合は対象外。
- 気象庁のWeb用公開JSONは開発者向けの保証付きAPIではないため、取得できない場合は取得失敗を表示する。ページを開くまでアメダスデータへの通信は発生しない（従来仕様を維持）。
- JMA公開JSONに品質0以外の値は採用しない。GPSの座標は気象庁に送信しない（全国地図JSONを読み込んで端末で近い観測所を抽出）。
- 自動補正、全国3モデルの長期検証、通知、手動天気記録、プライベートお気に入りの保存形式は変更しない。

## v0.45.1 iPhone表示不具合への対策
- v0.45の画面に気温比較欄が表示される一方、iPhoneのService Workerが以前の`amedas-nearby.js`を返し、風速と雨量のみ表示され、気温3欄が「—」と初期説明のまま残る場合があった。
- `index.html`の読み込みURLを`./amedas-nearby.js?v=0.45.1`にしてキャッシュを識別し、Service WorkerのプリキャッシュURLも同じに変更。以前のService Workerが有効でも、古いURLと一致せずオンラインで新版を取得する。
- 旧モジュールを検知したら「気温表示の更新がまだ反映されていないよ」と表示し、観測所が存在しないと誤認させない。
- 保存現場、私用お気に入り、通知設定、研究用データには変更なし。新規のアメダス温度情報は従来通り表示を展開した時だけ取得。
- 本番公開の成否とiPhoneの表示は別途確認する。
