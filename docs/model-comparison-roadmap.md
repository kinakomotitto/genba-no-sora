# 現場の空 — 複数気象モデル比較から検証済みの予報へ

更新：2026-11-10 / v0.27 比較機能の試作

## 目的
同じ時刻・地点の雨と風の予測が気象モデルによってどの程度違うかを正確に示し、十分な観測と検証が得られた後だけ、過去実績による補正・統合の可否を判断する。単純平均を「最適予報」と呼ばない。

## v0.27 実装
- 対象：JMA MSM、ECMWF IFS、DWD ICON Seamless（日本域ではGlobalの予報）。Open-Meteoが配信する異なる予報モデルであり、独立の3ウェブサイトからの取得ではない
- 現在地または選択現場の予報を同じ緯度経度、Asia/Tokyoの時間軸、10m風速・風向（m/s、度）、1時間降水量（mm）で照合
- 突風はECMWFとDWD ICONの提供時だけ比較。JMA MSMで提供されない突風は欠測扱い（0にはしない）
- ホームに折りたたみ比較カード。最大6時刻を選択でき、各モデルの数値と範囲・差を表示。最大値を隠さない
- モデルの1つが取得不能でも残りの予報を表示するが、1モデルしかない場合は比較済みと見なさない
- 取得時刻と、保存データが最新ではない旨を表示。取得日時はモデルの初期化・公表日時ではない
- 予測スナップショットは本人のiPhoneのlocalStorageだけに直近最大120レコード・14日を保持。各レコードには取得時刻、地点座標（小数3桁）、モデル名、対象時刻と予測値を保存。現場名やGPS座標をGitHubへアップロードしない
- プライバシー注意：予報APIリクエストでは選択した地点座標がOpen-Meteoへ送信される。端末内の保存だけとは異なる
- iOSのPWAはアプリを閉じたままではブラウザ内の取得・保存が進まない。端末内履歴は将来の本格自動学習の代用品ではない

## 次の段階と完了条件

### v0.28 — 検証用データ基盤
1. 公開観測所を3〜5か所選定。個人の現場や工事名ではなく、公開観測所の位置だけを対象とする
2. 利用条件を満たす経路で定期的に各モデルの予報を「取得した時点」の値として保存。モデルrun時刻が取得できる場合のみ区別して保持
3. 公開観測所の観測値（品質フラグ、測器高度、標高を含む）を適法・安定的に取得。推計・再解析値は実測と混同しない
4. 風速・風向・降水量を同じ観測時刻・予報対象時刻・単位・地点で照合。欠測を除外するが、失敗件数は記録する
5. 単一データ配信基盤の障害、API規約、収集失敗、データ鮮度を見える化する

### v0.29 — 精度評価
- モデルごとに風速MAE、過大・過小の偏り、強風見逃し率、風向の円周角誤差、降水量MAE、降水有無の的中・見逃しを記録
- 同じ日・地点の近接時刻を独立サンプルとして過大評価せず、予報リードタイム・季節・地形・地域で分ける
- 雨は予測降水量と降水確率を混同しない。JMA MSMにない確率を無理に補完しない
- 公式警報や現場作業中止基準は予報モデルの平均で上書きしない
- 最新データを学習・評価の両方に使わない。時系列ホールドアウトで検証する

### v0.30 — 条件付きの補正・統合
- 単独モデル、未補正の中央値、候補補正を未使用期間で比較
- 十分なサンプルで一貫して改善が確認された場合のみ補正を採用。採用条件と検証期間を画面に表示
- 差が大きい場合、複数モデルの予測範囲と強い風・雨の上振れを引き続き表示
- 評価不能・データ劣化時は自動補正を停止して元の予報に戻す
- 表示は「検証済み補正予測」とし、「絶対に当たる」「作業可能」としない

## 必須の利用条件
Open-Meteoの公開Free APIは非商用用途向け。営利会社の現場で継続利用する場合、個人試作であることだけで無条件に許容されるとは判断できない。運用前に利用規約、商用ライセンスまたは別の許諾済み取得方法を確認する。費用の発生するプランへ無断で移行しない。

## 2026-11-30前のモデル移行への対応
Open-Meteoの資料では旧「ICON Global」モデル識別子に2026-11-30の終了予定がある。v0.27の最初の実装では継続的な「ICON Seamless」の識別子を使用する（日本付近ではICONの全球予報）。旧IDを固定したままにしない。APIの実応答で配信停止や欠測がないか実機確認すること。

## v0.27.1 表示調整
対象時刻が18:00の場合、降水量は17:00〜18:00の1時間合計。18:18に閲覧したときに過去の17〜18時降水を「これからの予想」として見せないため、比較する最初の時刻を次の毎正時（19:00）からにした。予測降水量には雨・雪が含まれるため「雨量」でなく「降水」と明示し、単位はmm（前1時間合計）を採用。時間別風速・風向の値は対象時刻時点の予測値。
