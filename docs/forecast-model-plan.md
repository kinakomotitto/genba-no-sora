# 現場の空 — 予報比較・風の精度重視設計（調査メモ）

調査日: 2026-11-09。現在の実装 v0.8 と区別する。**以下は今後の設計方針であり、複数モデル比較・自動通知の実装完了を意味しない。**

## 結論
- Windy.comは**比較・検証用の重要な外部リンク**として採用。Windyは単独の「最も当たる予報」ではなく、複数の予報モデルを表示するサービス。
- Windyの「meteoblue AI（Learning MultiModel）」は多数のモデルと観測に基づく補正予報。ただし、日本の特定の伐採現場で最精度という独立した根拠は確認していない。**風の比較対象**とし、無断の自動取り込みは行わない。
- アプリ内の風の自動比較は、利用規約を満たすAPIが使える場合、**JMA MSM、ECMWF IFS、ICON Global**の3モデルから開始。いずれも日本で利用可能なモデルで、同じ時刻・地点・単位・高さ（10m）の値を比較する。
- 予報が一致している度合いを表示。**平均だけで危険な上振れを隠さない**。予報の最大値や差を併記し、極端な値を自動的に捨てない。

## モデルと役割
| モデル・サービス | 用途 | 原則 |
|---|---|---|
| JMA MSM（約5km） | 日本周辺の短時間・局地スケールの比較軸 | 基本の風速・風向は比較可。JMAのオリジナル配信には突風が含まれないため、他モデルと同列の「最大瞬間風速」にしない |
| ECMWF IFS（約9km） | 広域の風・雨の見通し | 10m風速・風向、突風予想を参照 |
| DWD ICON Global（約11km） | 別の全球モデルで予報差を確認 | 10m風速・風向、突風予想を参照 |
| Windy.com（meteoblue AI 等） | モデル比較／独立した参考画面 | Windyにワンタップで遷移。値の自動取得は権利確認ができるまで禁止 |
| 気象庁高解像度降水ナウキャスト | 直近0〜60分の降水の動き | 毎時の予報モデルと分けて表示し、雨雲接近情報の公式参照先にする |

## 表示例（以下すべて架空）
- 「風速予報 5 m/s 程度 / モデル範囲 3〜8 m/s」のように中央値と範囲を併記する。
- 「最大瞬間風速（予測）は ECMWF 12 m/s / ICON 15 m/s」のように**対応モデル別**に表示し、JMA MSMの空欄を「0」と扱わない。
- 風向は北=0°、単位はm/sで正規化。角度を単純に平均せず、風向ベクトルまたは円統計で集約する。
- 各モデルの**元の予報発表時刻／取得時刻、欠測、予報対象時刻**を表示。古い予報は「最新」と表示しない。
- 地形・樹木・伐倒地点による風の差が大きいため、現場での風や周囲の状況、会社の作業基準を最優先。表示の数字だけで作業可否を判定しない。

## 予報精度を本当に上げるための検証
1. 同じ現場・同じ時間・同じ高度（原則10m風）で複数モデルの予測を保存する。
2. 安全に取得できる観測（近隣アメダス等）と比較して誤差の傾向を確認。ただし、観測所と山林内の風は別物。
3. 観測のある地点ではMAE（平均絶対誤差）、強風見逃し率、風向誤差を比較。十分なデータが集まるまでは「このモデルが一番当たる」と判定しない。
4. 将来、現場ごとに予報の偏りを補正してよいが、学習データ不足時は重みを均等または未指定にする。

## 技術・ライセンスの確認事項
- 試作用のOpen-Meteo無償APIは**非商用利用のみ**。伐採会社の業務での利用は非商用と断定できないので、運用前に商用ライセンス・代替取得方法を確認する。
- Windy.com Point Forecast APIの**無料テスト値はランダム加工・シャッフル**されるため、実際の予報比較には使えない。プロ用APIでもECMWFはライセンス上含まれない。
- 複数の予報モデルをOpen-Meteoなど**同じAPI事業者経由**で取る場合、気象モデルは別でも配信障害の独立性はない。「3サイト」と誤記しない。
- 既存v0.8のデザイン（ピンク〜ラベンダー、下部日本語＋韓国語、文字タブ、アイコン「하늘」）は変更しない。
