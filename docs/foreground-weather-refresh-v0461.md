# 現場の空 v0.46.1 — iPhoneで長時間開きっぱなしの天気・現在地更新

## 報告
iPhoneのホーム画面で「オンライン」なのに、表示される地点・予報が更新されないことがある。写真には青森県八戸市と「最新取得 11/11 18:30」が写っていた。「オンライン」はネットワーク接続の指標であり、GPSやOpen-Meteoの更新成功とは独立。

**写真の撮影日自体は未確認**のため、11/11の表示だけで長時間古いデータが確定したとは言えない。ただし、既存コードはアプリを再表示するときに気象更新を起動せず、以前のGPSでネット回復時や手動更新を行う経路があった。

## 対策
- iPhoneのホーム画面PWAを長くバックグラウンドにしたあと再表示すると、現在地/予報が古い場合は自動更新。
- 前景復帰時に最後のチェックから10分未満なら不要な通信なし。現在地GPS/予報が15分以内なら再取得不要。両者が古い場合は新しいGPSで再取得。GPSが新しく予報だけ古い場合は予報のみ更新。
- ネットワークが切れたのち回復した場合も同じ鮮度チェック。古いGPSが残ったまま予報だけ取得しない。
- 気象更新ボタンを現在地で押したら必ず新しいGPSを取得し、その地点の予報へ更新。保存現場と私用で検索した地点はその場所の予報のみ再取得。
- 保存キャッシュを再表示するときは「保存データ」と表示し、GPSが失敗した場合も「前回の位置・予報が残っている場合があります」と注意する。
- ページの完全な再読み込み時にもGPSの5分キャッシュを使わない。
- Service Workerは別バージョンv0.46.1。保存データ・お気に入り・プッシュ購読・現場・研究データの保存形式や自動補正は変更しない。

## 動作検証
- `tests/test_foreground_weather_refresh.cjs` で、古いGPS/予報、最新のGPS、私用検索、ネット復旧、背景復帰、重複更新の制限を外部ネット/GPSなしで自動検証。
- 実機のiPhoneでの更新結果は別途ユーザー確認が必要。
- GitHub Actionsの全国3モデルの研究用データ収集失敗とは別の機能。研究用HTTP 400がPWAの天気更新を直接止める設計ではない。

## 今後の確認
ユーザーが撮った**現在のスクリーンショット**の「最新取得」日時と現在地が一致するかを見る。iOSのGPS許可が拒否された場合は端末設定の位置情報権限を確認。iPhoneのホーム画面PWAを削除すると端末内のお気に入り・保存現場に影響する可能性があるため、アプリ削除/サイトデータ削除を安易に勧めない。
