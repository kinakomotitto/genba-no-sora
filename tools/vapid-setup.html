✨ Cloudflareへ1つずつ登録

左の名前を「Key」に、右の文字列を「Value」に貼り付けてね。秘密鍵とSALTは必ず Secret にチェック！

① VAPID_PUBLIC_KEYText（公開鍵）
② VAPID_PRIVATE_KEYSecret（秘密鍵）
③ RATE_LIMIT_SALTSecret（非公開）

Cloudflareでの登録手順

  1. 通知サーバー → Settings → Runtime variables and secrets → Add variable
  2. この画面の「Key名」と「Value」を順番に貼り付け
  3. ②と③は Secret を選択。①はTextでOK
  4. Productionへデプロイしてから /health を確認

すでに登録した VAPID_SUBJECT はそのままでOK。公開鍵と秘密鍵は必ず同じ回で作ったペアを使ってね。もし再生成したら、両方更新してね。
